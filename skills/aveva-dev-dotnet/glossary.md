# Glossary: AVEVA Marine & Plant .NET Customisation

Alphabetical index of key terms, interfaces, and classes across CAF, Core Database, Marine Utility, UI, Welding, and Planar APIs.

- **AddinManager** — CAF 核心服务之一，负责管理应用程序插件的生命周期与程序集动态解析 (Ch 01)
- **Assign(that)** — PMLNet 和 Marine 对象约定的浅/深复制方法，类型需暴露给 PML 时为必备契约 (Ch 03, Ch 05)
- **BeadStatement** — 平面结构中的焊道加强筋或压筋语句类 (Ch 10)
- **BoundaryStatement** — 定义平面分段（Panel）外部闭合轮廓与外板/邻板修剪边界的语句类 (Ch 08)
- **BracketStatement** — 造船平面肘板语句类，封装两臂尺寸（ArmA/ArmB）、坡口及搭接板架关系 (Ch 09)
- **CAF (Common Application Framework)** — AVEVA 的通用应用程序框架，承载服务注入、窗体停靠、菜单命令与模块扩展 (Ch 01)
- **Clip** — 加强筋穿越板件时的夹板（卡马/嵌条）语句，用于封闭孔边间隙并传递剪力 (Ch 10)
- **Command** — 抽象命令基类，提供 `Key`、`Checked`、`Enabled` 状态及 `Execute()` 动作，与 UIC 按钮映射 (Ch 01)
- **CommandBarManager** — 负责管理宿主程序中菜单栏、工具条与快捷工具栏展示的 Presentation 服务 (Ch 01)
- **CompensationStatement** — 开孔边缘或板件局部受力补强板（Doubling Plate）补偿语句 (Ch 10)
- **ComponentHelper** — 平面分段构件导航工具类，支持反查宿主板架名称与子构件分组 (Ch 08)
- **CutStatement** — 定义板件边缘倒角或端部局部几何轮廓大范围切除的工艺语句 (Ch 10)
- **Dabacon** — AVEVA 底层专有的高性能工程数据库系统，以层级树和属性块存储全部三维模型数据 (Ch 02)
- **DbAttribute** — 数据库属性定义类，包含属性名称、数据类型与元数据描述 (Ch 02)
- **DbAttributeInstance** — 预置全部原生系统属性（如 `NAME`, `DESC`, `POSX`, `XLEN`）的只读单例集合 (Ch 02)
- **DbElement** — Dabacon 数据库图元实体的统一强类型封装指针，具备值语义比较与生命周期校验 (Ch 02)
- **DbElementType** — 数据库图元类型标识类（如 `EQUI`, `PIPE`, `PANEL`），支持标准类型与用户自定义扩展类型 UDET (Ch 02)
- **DbElementTypeInstance** — 预置全部原生元素类型静态常量的只读单例集合 (Ch 02)
- **DbEvents** — Dabacon 核心变更事件总线，提供 `TransactionEvent` 与 `AttributeChangeEvent` 实时监听 (Ch 02)
- **Direction** — 三维单位空间方向向量，支持余弦分量、叉乘法向与夹角运算 (Ch 02)
- **DockedWindow** — 宿主界面下的停靠窗体封装，支持拖拽停靠在左、右、底及多标签页自动切换 (Ch 01)
- **DoublePlateStatement** — 双层底或夹层复合板架的专用结构语句 (Ch 08)
- **ExcessStatement** — 船体建造合拢边缘加放余量（Green Margin）语句，预留现场合拢修割尺寸 (Ch 10)
- **FixedHeaderOnColumns** — `GridControl` 冻结列头机制，确保横向滚动时主标识列常驻可视 (Ch 04)
- **FlangeStatement** — 强框架或实肋板自由边焊接面板（Face Plate）语句类 (Ch 09)
- **GenerateSketch** — `MarPinProfiles` 的下料草图与活络样箱投影线生成方法 (Ch 07)
- **GridControl** — AVEVA 官方包装的高性能 WinForms 数据表格控件，支持列筛选、行着色、输入掩码与 Excel 导出 (Ch 04)
- **HNCStatement** — Hole-Notch-Clip 三合一复合孔切卡马特征语句 (Ch 10)
- **HoleStatement** — 板架上的人孔、管穿孔、透气减重孔等标准化特征语句 (Ch 10)
- **IAddin** — 所有 CAF 插件的根入口接口，定义 `Name`、`Description`、`Start` 与 `Stop` (Ch 01)
- **MarDataBase** — Marine 专有数据库查询网关，提供构件与图纸列表快速检索 (Ch 05)
- **MarNone** — Marine 专用空对象/无效值哨兵类，用于判断返回句柄是否有效 (Ch 05)
- **MarObject** — Marine 原生实体包装基类，实现 `IDisposable` 与 `Assign` 方法 (Ch 05)
- **MarPinProfiles** — 曲面外板拼装活络样箱（Pin Jig）高度矩阵与型线阵列计算引擎 (Ch 07)
- **MarPythonEngine** — 宿主内部嵌入式 Python 解释器运行实例，用于驱动 Vitesse 脚本 (Ch 06)
- **MarUi** — Marine 专有轻量级原生交互服务，提供弹窗输入、颜色选取及视口刷新 (Ch 06)
- **MarUtil** — 通用造船工具服务，负责命令行注入（`AddCommand`）、坐标变换及应用子系统判断 (Ch 05)
- **MarWeld** — 单条实体焊缝的工艺与几何属性封装（长度、厚度、坡口类型、材质） (Ch 07)
- **MarWeldedJoint** — 两个或多个相接结构件之间的焊接节点关系与焊道集合 (Ch 07)
- **My Data** — AVEVA 官方会话级实体收藏夹与临时数据聚合系统 (Ch 04)
- **NotchStatement** — 流水孔（Drain Hole）、透气孔（Air Hole）及骨材穿越缺口语句 (Ch 10)
- **Orientation** — 构件在三维空间中的旋转姿态类，由局部 Y 轴与 Z 轴指向定义 (Ch 02)
- **PanelStatement** — 造船平面分段（Planar Panel）核心语句类，统领母板、型材与开孔 (Ch 08)
- **PlaneStatement** — 平面分段在船体全船空间中的空间参考基准面（肋位、纵剖面或水线面）语句 (Ch 08)
- **PlateStatement** — 平面板架上的钢板母板语句，定义板厚、钢级与搭接轮廓 (Ch 09)
- **PmlNetCallableAttribute** — 标记 C# 类、方法或构造函数可被 PML 运行时识别的核心特性 (Ch 03)
- **PmlNetControl** — PML 表单中专用于宿主 WinForms/WPF 托管控件句柄的容器组件 (Ch 03)
- **PMLNetDelegate.PMLNetEventHandler** — C# 向 PML 派发异步事件的标准委托签名 (Ch 03)
- **PMLNetEngine** — 宿主内负责解析程序集并为 PML 自动生成透明运行时代理解析器的核心引擎 (Ch 03)
- **PMLNetException** — 从 .NET 向 PML 抛出可捕获错误代码的专用异常类 (Ch 03)
- **Position** — 三维绝对空间笛卡尔坐标点类（East, North, Up），提供距离测量与向量偏移 (Ch 02)
- **PseudoAttribute** — 自定义伪属性注册机制，允许使用 C# 委托向图元挂载动态计算属性 (Ch 02)
- **SeamStatement** — 拼板缝语句，定义母板如何被数控拼缝切分为单块钢板 (Ch 10)
- **ServiceManager** — CAF 服务定位器与服务总线，通过 `GetService` 获取窗口、命令与设置管理 (Ch 01)
- **ShrinkageStatement** — 焊接收缩补偿语句，用于抵消切割下料与焊接冷却造成的尺寸形变 (Ch 10)
- **StiffenerEndConnection** — 型材端切连接定义类，涵盖斜切、齐切、角隅释放及相贯扣合 (Ch 09)
- **StiffenerStatement** — 平面型材加筋语句类，定义间距（M1）、角度（T）、倾角（INC）及端部连接 (Ch 09)
- **SwageStatement** — 波形折边板语句，用于油轮/散货船无骨架波形舱壁（Swaged Bulkhead）折压建模 (Ch 10)
- **TAPStatement** — Tool/Attachment/Penetration 工艺穿越件语句，定义电缆管穿舱套管或装配吊环孔 (Ch 10)
- **UIC 文件 (*.uic)** — 基于 XML 的用户界面配置描述文件，用于静态绑定命令与菜单/工具条 (Ch 01)
- **WindowManager** — CAF 窗口管理器，提供创建停靠窗体与浮动面板的统一方法 (Ch 01)
