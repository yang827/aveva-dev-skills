# Glossary of AVEVA PML & Marine Customisation Terms

Comprehensive dictionary of PML 1, PML 2, DABACON, Application Framework, SCRM System Objects, and Marine Drafting terms cross-referenced with chapter locations.

---

**Alert** — Native modal dialog object (`!!ALERT`) providing Message, Warning, Error, Confirm, Question, and Input popups. (Ch 4, Ch 7, Ch 17)
**Alpha View** — View gadget type (`view ... alpha`) that displays an embedded text console inside a PML form. (Ch 9, Ch 11)
**Anchoring** — Layout directive (`<fganch>`) controlling how gadget borders resize or stretch when a form window is resized. (Ch 9)
**AnswerReqPML** — Official TM-2401 `MarUi` method displaying an interactive question dialog returning system button codes (`YesPML()`, `NoPML()`, `CancelPML()`). (Ch 14, Ch 15)
**APPMENU** — Application Framework object used to insert custom menus and toolbars into module menu bars without editing core files. (Ch 10)
**ARRAY** — Dynamic, 1-based heterogenous list of variables or objects initialized via `ARRAY()`. (Ch 2, Ch 7, Ch 17)
**autoquit** — Button gadget modifier causing the enclosing form to close automatically when the button callback completes. (Ch 8, Ch 9)
**BadRef** — Built-in `DBREF` method (`!ref.badRef()`) returning `TRUE` if the database reference is invalid or points to a non-existent element. (Ch 2, Ch 7, Ch 13, Ch 17)
**BARMENU** — Top-level menu bar container defined within a form or window layout. (Ch 10)
**BOM** — Byte Order Mark; required encoding prefix for UTF-8 files in AVEVA 12 Series. (Ch 4, Ch 16)
**BOOLEAN** — Primitive logical data type taking values `TRUE` or `FALSE`. (Ch 2, Ch 7, Ch 17)
**BOX** — 3D geometric solid primitive defined by length dimensions `XLEN`, `YLEN`, and `ZLEN`. (Ch 18)
**BREAK** — PML statement immediately terminating the innermost enclosing `DO` loop. (Ch 3)
**BUTTON** — Interactive GUI push button gadget invoking a callback method or command expression. (Ch 8, Ch 9)
**cancelcall** — Form attribute defining the callback executed when the user clicks Cancel or presses Esc. (Ch 8)
**CLIPBOX** — 3D spatial boundary filter restricting rendering in a graphical viewport to a localized volume. (Ch 11, Ch 19)
**Clone (.clone())** — Universal object method creating an isolated, deep duplicate of an object and its child references. (Ch 2, Ch 17)
**COLLECTION** — High-performance PML 2 database search object supporting `.type()`, `.scope()`, `.filter()`, and `.results()`. (Ch 13, Ch 17, Ch 19)
**CONTAINER** — Scrollable panel container gadget hosting nested gadgets or child forms. (Ch 9, Ch 17)
**Coordinate Translation** — MarAPI coordinate conversion methods (`!marUtil.TraCoordShip`, `!marUtil.TraCoordPan`, `!marDraft.PointTranform`, `!marUtil.CoordToPos`) translating between drawing sheet `(U,V)`, ship global `(X,Y,Z)`, panel local `(U,V,W)`, and structural frame notations. (Ch 14)
**Current Element (!!CE)** — Global built-in `DBREF` variable tracking the actively selected element in the database. (Ch 2, Ch 5, Ch 7, Ch 13)
**CYLINDER** — 3D geometric cylindrical primitive defined by diameter `DIAM` and height `HEIG`. (Ch 18, Ch 19)
**DABACON** — AVEVA's hierarchical, transactional engineering database holding all 3D design and schematic models. (Ch 2, Ch 13, Ch 17)
**DBREF** — Database Reference system object acting as a direct pointer to an element in DABACON. (Ch 2, Ch 7, Ch 13, Ch 17)
**define function** — PML 2 declaration for standalone procedure files stored in `.pmlfnc`. (Ch 5)
**define method** — Declaration for object-oriented methods stored in `.pmlobj` or `.pmlfrm`. (Ch 6, Ch 8)
**define object** — PML 2 declaration defining state and members of a User-Defined Object. (Ch 6)
**dialog** — Form modifier creating a modeless utility window with a thin border and no minimize/maximize controls. (Ch 8)
**DIRECTION** — 3D spatial system object representing a directional vector with `.angle()` and `.vector()` methods. (Ch 7, Ch 17)
**DISH** — 3D geometric solid primitive representing a dished head defined by `DIAM` and crown `HEIG`. (Ch 18, Ch 19)
**Docking** — Layout directive (`<fgdock>`) fixing a gadget to the top, bottom, left, right, or fill of its container. (Ch 9)
**dtext** — Property on `LIST` and `OPTION` gadgets holding the `ARRAY of STRING` displayed to the user. (Ch 8, Ch 9, Ch 19)
**DwgClose** — `MarDrafting` method closing the currently loaded drawing sheet. (Ch 14)
**DwgCurrent** — `MarDrafting` method returning `TRUE` if a drawing is currently active in Marine Drafting. (Ch 14)
**DwgSave** — `MarDrafting` method saving the current drawing to the drawing databank. (Ch 14)
**edgCntrl (!!edgCntrl)** — Global singleton controller for Event Driven Graphics, managing the active 3D pick event stack. (Ch 12, Ch 17)
**edgPacket** — EDG application packet encapsulating tool identity, form linkage, and action callbacks. (Ch 12, Ch 17)
**edgPick** — EDG object defining graphical canvas pick behavior, cursor styles, and highlight filters. (Ch 12, Ch 17)
**edgPickData** — Event payload delivered to the `.action()` callback carrying the picked reference and normal vector. (Ch 12, Ch 17)
**edgPickPacket** — Sequence controller orchestrating multi-step 3D picks and cursor prompts. (Ch 12, Ch 17)
**edgPickType** — EDG class defining how canvas hits are decomposed (DBREF pointer vs Point/Line/Plane geometry). (Ch 12, Ch 17)
**ElementIsView** — Marine Drafting method testing if a `MarElementHandle` represents a drawing view. (Ch 14)
**ELSEHANDLE** — Secondary branch inside a `HANDLE` block matching specific error numbers or `ANY`/`NONE`. (Ch 4, Ch 16, Ch 19)
**ENHANCE** — Command applying temporary visual color highlighting to 3D elements in a graphical view. (Ch 11, Ch 12, Ch 19)
**EXPRESSION** — PML system object encapsulating a logical or arithmetic condition for database filters. (Ch 13, Ch 17)
**FILE** — System object managing operating system disk file streams (`.openFile()`, `.readRecord()`, `.writeRecord()`, `.closeFile()`). (Ch 7, Ch 17)
**firstcall** — Form event attribute executing a callback exactly once the first time the window is displayed. (Ch 8)
**FMSYS (!fmsys)** — Application Framework forms manager system object controlling window registration, clipboard, cursors, and swapping. (Ch 8, Ch 10, Ch 17)
**FOLDUP** — Collapsible container frame gadget that can be expanded or collapsed by clicking its header. (Ch 9)
**FORMAT** — System object managing precision and engineering unit formatting for numbers. (Ch 7, Ch 9, Ch 17)
**FRAME** — Visual container gadget grouping child gadgets; supports standard, tabset, and foldup modes. (Ch 8, Ch 9, Ch 19)
**HANDLE** — Error interception statement placed immediately after a risky command. (Ch 4, Ch 16, Ch 19)
**initcall** — Form event attribute executing a callback every time the form is shown on screen. (Ch 8, Ch 19)
**LINKLABEL** — Hyperlink-style button gadget inside a PML form. (Ch 9)
**LIST** — Scrollable list box gadget supporting single or multiple selections. (Ch 8, Ch 9, Ch 19)
**MarAPI** — AVEVA Marine .NET interoperability assembly providing core drafting and UI classes. (Ch 14, Ch 15)
**MarCaptureRegionPlanar** — 2D planar boundary object used to geometrically collect drawing elements. (Ch 14)
**MarDrafting** — Primary Marine Drafting automation class managing drawings, views, and layers. (Ch 14)
**MarElementHandle** — Opaque numeric handle representing an element on a Marine drawing sheet. (Ch 14)
**MarPointPlanar** — 2D drawing plane coordinate point `(X, Y)`. (Ch 14)
**MarUi** — Marine user interface message dialog class (`MessageConfirm`, `MessageNoConfirm`, `AnswerReqPML`, `StringReqPML`). (Ch 14, Ch 15)
**MarUtil** — Marine utility class providing button return codes (`YesPML()`, `OkPML()`), coordinate tools, and environment variables. (Ch 14, Ch 15)
**MARK** — Command setting a transactional checkpoint in the DABACON database session. (Ch 4, Ch 17)
**mcount** — Native `DBREF` method returning the count of child members (`!ref.mcount()`). (Ch 7, Ch 13, Ch 17)
**MDB** — Multiple Database configuration defining the readable/writable databases in the active project. (Ch 17)
**noalert** — Option on `RETURN ERROR` suppressing modal popup dialogs during automated execution. (Ch 4)
**NUMERICINPUT** — Input gadget designed specifically for formatted real numbers with unit handling. (Ch 9, Ch 17)
**OPTION** — Drop-down combobox gadget for single-choice selection from an array of strings. (Ch 8, Ch 9, Ch 19)
**ORIENTATION** — 3D spatial rotation matrix system object specifying reference axis directions. (Ch 7, Ch 17, Ch 18)
**PARAGRAPH** — Static text or icon display gadget inside a form. (Ch 8, Ch 9, Ch 19)
**PointPlanarReqPML** — `MarUi` interactive point request method supporting 5 cursor types (`CrossHair`, `RubberBand`, etc.). (Ch 14)
**PML 1** — Legacy macro scripting layer using `.mac` files, `$1`..`$9` parameters, and `$GOTO`. (Ch 1, Ch 16)
**PML 2** — Strongly-typed object-oriented language layer using `.pmlfnc`, `.pmlobj`, and `.pmlfrm`. (Ch 1, Ch 5, Ch 6, Ch 8)
**pml rehash all** — Essential command processor directive forcing PML to rebuild its index of `PMLLIB` files. (Ch 1, Ch 5, Ch 8, Ch 16)
**pml reload form** — Command reloading a form definition directly from disk without restarting AVEVA. (Ch 8)
**pml trace** — Debugging command suite tracing line execution, variable modifications, and commands. (Ch 4)
**pmladd** — Descriptor file format used by the Application Framework to dynamically register PML Add-ins. (Ch 10)
**PMLLIB** — Operating system environment variable defining the directory search path for PML 2 source files. (Ch 1, Ch 5, Ch 8)
**POSITION** — 3D spatial coordinate system object `(East, North, Up)` with vector calculation methods. (Ch 7, Ch 17)
**PROGRESSBAR** — GUI gadget providing visual feedback for long-running iterative tasks. (Ch 9)
**REDO** — Command re-applying database changes previously reverted via `UNDO`. (Ch 4, Ch 17)
**Reference Type** — Object or Array whose assignment creates an alias pointing to shared memory. (Ch 2, Ch 17)
**RETURN ERROR** — Statement raising a custom domain exception up the call stack. (Ch 4, Ch 5, Ch 16)
**RTOGGLE** — Radio toggle gadget operating within a mutually exclusive radio group. (Ch 9, Ch 17)
**SELECTOR** — Native DABACON database tree navigation gadget embedded inside forms. (Ch 9, Ch 17)
**setup form** — PML 2 keyword initiating a form UI definition block. (Ch 8, Ch 9, Ch 19)
**SKIP** — PML statement skipping the remainder of the current iteration in a `DO` loop. (Ch 3)
**SLIDER** — Horizontal or vertical slider control gadget. (Ch 9, Ch 17)
**STRING** — Primitive text sequence data type delimited by single quotes or pipe characters. (Ch 2, Ch 7, Ch 17)
**StringReqPML** — `MarUi` dialog method requesting text input from the user with default value support. (Ch 14)
**Synonym ($S)** — Command line abbreviation or alias declared via `$S <alias> <command>`. (Ch 1, Ch 3)
**TABSET** — Frame gadget style rendering child frames as tabbed notebook pages. (Ch 9)
**TEXT** — Single-line text input gadget inside a form. (Ch 8, Ch 9)
**TEXTPANE** — Multi-line scrollable text editing gadget inside a form. (Ch 9, Ch 17)
**this** — Keyword representing the current instance inside object or form methods (`!this.var`). (Ch 6, Ch 8)
**TOGGLE** — Checkbox gadget holding a `BOOLEAN` state. (Ch 9, Ch 17)
**TOOLBAR** — Container gadget hosting icon buttons and tool controls. (Ch 10)
**UNDO** — Command reverting database changes made since the last `MARK` checkpoint. (Ch 4, Ch 17)
**Value Type** — Scalar data type (`REAL`, `STRING`, `BOOLEAN`) whose assignment creates an independent copy. (Ch 2, Ch 17)
**VIEW** — Embedded graphical viewport gadget supporting volume, plot, and alpha rendering. (Ch 9, Ch 11, Ch 19)
**Volume View** — 3D interactive shaded model viewport gadget embedded inside a form. (Ch 9, Ch 11, Ch 19)

**&+** — PML 1 no-space string concatenation operator joining strings without intervening spaces. (Ch 1, Ch 2, Ch 20)
**$S- / $S+** — Command processor directives to disable (`$S-`) or re-enable (`$S+`) synonym substitution. (Ch 1, Ch 3)
**$Q syserror** — Command processor diagnostic query printing the latest system error code and message. (Ch 4)
**BADREF** — SCRM Appendix A logical function returning `TRUE` if a database reference or ID is invalid or `NULREF`. (Ch 20)
**CoordToPos** — `!marUtil` method translating global coordinates along an axis to ship structural frame notations (e.g. `FR50+200`). (Ch 14)
**DimLinearNew** — `!marDraft` method creating 2D linear dimension entities (normal, chain, staircase). (Ch 14)
**ElementDbrefGet** — `!marDraft` method resolving a 2D drafting element handle to its underlying DABACON `DBREF` integer pointer. (Ch 14)
**Fold Up Panel** — Collapsible accordion container frame supporting `.fold()` and `.unfold()`. (Ch 9)
**MarDataBase** — `Aveva.Marine.Utility` class querying marine hull databases via `MarObjectCriteria`. (Ch 14)
**MarDex** — High-speed hull data extraction class in `Aveva.Marine.DataExtraction` utilizing the `NextResultPML` state machine. (Ch 14)
**MATCHWILD** — SCRM Appendix A wildcard pattern matching function supporting `*` and `?`. (Ch 20)
**NINT** — SCRM Appendix A nearest integer rounding function (`NINT(3.5) = 4.0`, `NINT(-3.5) = -4.0`). (Ch 20)
**NoteNew / PosnoNew** — `!marDraft` methods creating structural notes and position number balloons with leader lines. (Ch 14)
**PointTranform** — `!marDraft` method transforming 3D global ship coordinates to 2D drawing sheet coordinates. (Ch 14)
**Tabset Frame** — Multi-page container frame hosting multiple tabbed screens within a form canvas. (Ch 9)
**TraCoordPan** — `!marUtil` method translating 2D drawing sheet points to 3D panel local coordinates `(U,V,W)`. (Ch 14)
**TraCoordShip** — `!marUtil` method translating 2D drawing sheet points to 3D global ship coordinates `(X,Y,Z)` on a structural panel. (Ch 14)
